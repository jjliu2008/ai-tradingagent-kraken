Architecture

Research-driven. Execution-disciplined.

Instead of one fixed strategy, this agent runs a continuous research loop — screening, diagnosing, ranking, and promoting pairs based on evidence.

01 / DAILY
🔬

Pair Screening

Screener runs across all Kraken pairs, scoring each on full 120d, older 60d, and recent 60d windows to find strategies that survive both weak and strong sub-periods.

02 / DAILY
🩺

Segment Diagnostics

Per-pair behavioral diagnostics extract suppression notes, trend consistency, and regime sensitivity before any candidate is considered for promotion.

03 / DAILY
📊

Portfolio Ranking

Candidates are ranked by their actual add/replace impact on the current live book — not isolated Sharpe — so promotions improve the portfolio, not just look good alone.

04 / 15-MIN
⚡

Intraday Execution

The execution agent trades only the validated research registry. Risk guardrails, suppression state, and pair-specific config gate every entry and exit.

Trust & Safety

Built to be auditable, not just profitable

Every promotion is inspectable. Every trade intent is signed. Risk guardrails gate every cycle.

🛡️

Risk Guardrails

Hard limits on notional exposure, position count, and drawdown. Suppression logic reduces or blocks new entries during weak regime conditions automatically.

📋

Proposal Artifacts

Before any pair joins the live book, the system writes a versioned proposal artifact showing what it wants to promote, why, and what it replaces — making promotions auditable.

⛓️

ERC-8004 Integration

Pre-trade intent signing and post-trade feedback logging on Base Sepolia. Builds an on-chain reputation trail that is verifiable independent of the agent's own logs.

🧪

Paper Trading Default

All demo and strategy-development paths run in paper mode against live Kraken prices. No real capital at risk during research iteration.
